# Register Architecture

## Purpose

The Register Architecture defines how business facts are stored, aggregated, queried, and propagated throughout the AcCore platform.

Registers are the primary mechanism for representing operational and accounting facts generated by business activities.

Register Architecture provides:

* Information storage;
* Accumulation storage;
* Aggregation mechanisms;
* Balance calculation;
* Turnover calculation;
* Query services;
* Dependency integration;
* Event publication.

---

## Architectural Principles

### Fact-Based Architecture

Registers store facts.

Derived data must not be stored as primary facts.

### Separation of Facts and Aggregates

Movements are primary data.

Balances and turnovers are derived data.

### Service-Oriented Processing

Register data is passive.

Register behavior is implemented through services.

### Query Independence

Consumers query registers through register services.

Consumers must not access totals storage directly.

### Dependency Integration

Registers publish changes.

Dependency Graph manages propagation and recalculation.

---

## Register Types

AcCore defines two register categories:

* Information Registers
* Accumulation Registers

Each category shares a common logical model while providing different runtime behavior.

---

## Core Components

### Information Registers

Store informational facts.

### Accumulation Registers

Store accounting movements.

### Totals Engine

Maintains aggregated register state.

### Register Services

Provide movement management, querying, aggregation, and maintenance.

### Register Events

Publish register state changes.

### Dependency Integration

Connect registers to the Dependency Graph.

---

## Architectural Responsibility

Register Architecture is responsible for:

* Register fact storage;
* Movement management;
* Aggregation management;
* Query execution;
* Event publication;
* Dependency participation.

Register Architecture is not responsible for:

* Business logic;
* Posting logic;
* Valuation logic;
* Reporting logic.
