# Phase 12 — Integration
## Slice 7 implementation notes

**Status:** Implementation candidate; local project quality gates still required.

This change adds a small standard-library JSON/HTTP transport adapter, a concrete Standard Inventory Balance export contract, and the logical contract/binding boundary for Standard Goods Receipt import.

## HTTP adapter

`accore.platform.integration.JsonHttpIntegrationAdapter` exposes four `POST` routes:

- `/v1/commands`
- `/v1/queries`
- `/v1/imports`
- `/v1/exports`

The request body is a JSON object with `contract`, `payload`, and an optional `request_identity`. `contract` contains `namespace`, `name`, `major`, `minor`, and `kind`. The request identity is generated by the adapter when omitted. Payload decoding is registered by the complete `IntegrationContractIdentity`; no client-controlled Python type names are resolved.

Example command envelope:

```json
{
  "contract": {
    "namespace": "standard.processing",
    "name": "inventory.rebuild",
    "major": 1,
    "minor": 0,
    "kind": "command"
  },
  "payload": {}
}
```

The host creates and starts the server:

```python
adapter = JsonHttpIntegrationAdapter(
    service=composition.service,
    import_export_service=composition.import_export_service,
    payload_decoders=payload_decoders,
    security_context_factory=trusted_security_context_factory,
)
server = adapter.make_server(("127.0.0.1", 8080))
server.serve_forever()
```

The example is illustrative: `payload_decoders` must match the registered contracts, and the host must provide a real authentication/session handoff. Bind the server to a trusted interface and deploy behind the application's approved network/TLS boundary. The adapter does not implement TLS, authentication, or identity-provider integration.

Request size is bounded (1 MiB by default). Responses are JSON, include `Cache-Control: no-store`, and do not expose unexpected exception details. Error categories map to stable HTTP statuses. Only `POST` is supported.

## Standard Import and Export

### Standard Inventory Balance Export

`standard.reporting / inventory.balance / 1.0 / export` is registered by default. It reuses the existing `ReportRuntime` and requires an existing compiled `ReportExecutionPlan` for the Standard Inventory Balance report. JSON serialization is provided by `JsonExportFormatAdapter`.

The HTTP host must supply a trusted payload decoder that builds/obtains the approved report plan. It must not accept arbitrary client-supplied Python objects or plans.

### Standard Goods Receipt Import

`standard.posting / goods-receipt.import / 1.0 / import` defines and validates a logical Goods Receipt payload. `decode_standard_goods_receipt_import_payload` converts JSON line quantities to `Decimal` and validates required product, warehouse, and positive finite quantity values.

The operation is registered only when `compose_standard_integration(..., goods_receipt_import_executor=...)` receives a host-owned executor. This is intentional: the current Standard source has a `GoodsReceiptPostingHandler`, but does not expose a complete application service that creates/persists a Goods Receipt document, establishes its durable document state, applies authorization, and invokes `PostingAPI`. The executor must perform that real business path; it must not write register movements directly or treat validation-only as a successful import. Until that application service is wired in, the import contract/binding is implemented but the Standard import is not available in the default composition.

This dependency is the remaining integration point for full Phase 12 closure; do not mark the phase fully closed merely because the transport adapter and contract tests pass.

## Security

The HTTP request body cannot set the `SecurityContext`. The adapter asks the injected host `security_context_factory` to establish it. The factory must derive identity from a trusted authentication boundary, not from arbitrary JSON fields or unverified headers. Runtime-owned authorization remains authoritative at the existing Runtime boundary.
